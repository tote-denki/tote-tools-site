# 照明配置プランナー DECISIONS

## 2026-11-05 v0.1.0 初版の範囲と計算方式
- 採用: 逐点法（直接照度のみ）で作業面の照度分布を出し、平均・最小・最大・均斉度（Emin/Eavg）を表示する
  → 理由: 照明台数 概算ツールは光束法の平均照度しか出せず、「ムラ」を見られないのが一番の差。ここを詰めるのがプランナーの役目
- 採用: 配光は I(θ)=I₀cosⁿθ の回転対称モデル（n=1/2/4 の3択）。I₀=F(n+1)/2π で全光束から逆算
  → 理由: 器具データを内蔵しない方針（概算ツールと同じ）のまま、全光束だけで分布を出せる。式が短く検算できる
- 不採用: IES/LDT 配光データの読込
  → 理由: ファイル形式の解析と検証に時間がかかり、v0.1 の範囲を超える。要望が出たら v0.2 以降で検討
- 不採用: 相互反射（ラジオシティ等）の計算
  → 理由: 反射率の入力が増え、検算できる人がいなくなる。直接照度は安全側（実際より暗く出る）なので、まずはこれで出す
- 不採用: n を自由入力にすること
  → 理由: 実器具との対応が説明できない値が入るのを避ける。3段階で十分に「広い／狭い」の差は見える
- 採用: 光束法の台数と平均照度も並べて表示する
  → 理由: 概算ツールとの対応が分かるように。ただし U は入力値なので、逐点法の値と一致しない旨を画面に書く
- 仮定: 器具は真下向きの点光源、配置は等分割格子（壁際は半ピッチ）。照明台数 概算ツールの配置と同じ考え方

## 2026-11-05 v0.1.0 自動配置で台数を足す扱い
- 採用: 自動モードは光束法の N 台を格子に割り付け、格子の空きは器具を足して埋める。足した台数は結果に必ず表示する
- 不採用: 概算ツールと同じく空きを残す（N 台ちょうど）
  → 理由: 欠けた格子の位置で分布が偏り、均斉度の評価が「抜けた場所」に引きずられる
- 不採用: 黙って台数を変える
  → 理由: 規約の「黙って値を直さない」。足した事実と台数を表示・印刷に出す

## 2026-11-05 v0.1.0 上限と停止の扱い
- 採用: 器具 1000 台・計算点 20000 点を超えたら計算を止めて理由を出す
- 不採用: 計算点の間隔を自動で広げて続行する
  → 理由: 間隔は結果（最小照度）に効く。勝手に変えると同じ入力から違う結果に見える
- 採用: 計算点はマス中心。実際の間隔（指定値以下）を結果に表示する

## 2026-11-05 v0.1.0 公開の扱い
- 採用: ページは noindex のまま、トップページの「準備中」表記も変えない
  → 理由: note 記事・販売形態（Pattern B か無料公開か）は荻野さんが決める。ツール側は動く状態にしておくだけ
- 採用: ファイル名は index.html（サイトの URL /lighting-planner/ のため）。版数は画面・印刷・JSON・この記録で管理
  → 理由: 照明台数 概算ツールと同じ扱い。規約2章の「ファイル名に版数」はサイト配信ファイルでは適用しない
