## 2. データ構造（JSON）
```json
{
  "app": "tote-lighting-planner",
  "version": "0.1.0",
  "savedAt": "ISO8601",
  "projName": "案件名", "roomName": "室名",
  "inputs": {
    "proj": "", "room": "",
    "w": "12", "l": "8", "h": "2.2", "e": "500", "u0": "0.6",
    "f": "6900", "m": "0.8", "uf": "0.6",
    "cols": "", "rows": "", "step": "0.5", "mg": "0.5",
    "n": "1", "mode": "auto"
  }
}
```
- inputs は入力欄の文字列をそのまま持つ（読込時に同じ文字列を戻すので、同じJSONから同じ結果になる）
- 計算結果を変える設定（n・mode・step・mg を含む）はすべて inputs に入る
- 最上位の未知キーは extraTop、inputs の未知キーは extraInputs に退避し、保存時に書き戻す
- 読込時に拒否するもの: app 違い、inputs なし、n が 1/2/4 以外、mode が auto/manual 以外

## 3. 計算ロジック
- 配光: I(θ)=I₀cosⁿθ、I₀=F(n+1)/2π
- 点Pの水平面照度: E=Σ M·I₀·h^(n+1)/d^(n+3)（＝I₀cosⁿ⁺¹θ/d²）、d=√(r²+h²)
- 器具位置: ((i+0.5)W/cols, (j+0.5)L/rows)
- 計算点: 壁から mg 内側の範囲を ceil(幅/step) 等分したマスの中心
- 光束法: N=⌈W·L·E÷(F·M·U)⌉、自動配置は概算ツールと同じ pickGrid（余り×0.30＋ピッチ縦横比の対数）
- 丸めは表示時のみ
- 検算: 器具1台・F=1000lm・n=1・h=2m・M=1 の真下 = 318.31/4 = 79.6 lx → 画面表示 80 lx（2026-11-05 Playwright で確認）

## 4. 既知の制限・未確定事項
- 直接照度のみ（相互反射なし）。実際の照度は表示より高い
- 配光は簡易モデル。実器具の IES/LDT は読めない
- 長方形の部屋のみ。柱・梁・什器・開口は扱わない
- 器具は真下向きの点光源。線光源の長さ・照射方向は扱わない
- 目標均斉度の既定値 0.6 は入力の初期値にすぎず、基準値として検証していない（画面にも「適用する基準で確認」と表示）
