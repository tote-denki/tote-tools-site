## 1. 変更点（v0.1.0 → v0.2.0）

(1) PDF印刷の改ページ
- 起きていたこと：「簡易配置案」の見出しが1ページ目の末尾に残り、図が2ページ目に送られていた。
- 直し方：印刷用の各セクション（見出し＋本体）を `.p-sec` で囲み、`break-inside: avoid` を付けた。見出し（h2/h3）は `break-after: avoid`。計算式・注意書き・配置案のブロックも分割させない。
- 確認：T1 を Chromium の印刷で A4 2ページに出力。入力条件・計算結果は1ページ目、簡易配置案・計算式・注意書きは2ページ目で、見出しと本体が分かれないことを確認。

(2) 器具光束欄の注記
- 入力欄の下に「カタログの器具光束（lm）を入れてください。保守率・利用率を掛ける前の値です。」を常時表示。値の自動補正はしない。

(3) 採用台数（任意）の追加
- 入力欄 `i-n`（整数のみ。小数は黙って丸めずエラー）。空欄なら計算台数を使う。
- 結果欄に「計算台数（切り上げ前／後）」と「採用台数」を並べて表示。
- 実効平均照度・受け持ち面積・配置案は採用台数で計算。
- 採用台数 < 計算台数 のとき、結果の近くに警告：「採用台数が計算台数を下回っています。実効照度 ◯◯ lx は必要照度 ◯◯ lx 未満です。」
- 「偶数に切り上げ」ボタンは採用台数欄に値を入れるだけ（自動では入れない）。
- 印刷にも計算台数と採用台数の両方を出す。

(4) 1列（1行）配置のときの表示
- 列数（行数）が1の方向は「ピッチ」ではなく「壁から器具中心まで ◯.◯◯ m（寸法÷2）」と表示。
- 間隔÷判定高さは、器具がある方向（列・行が2以上）のピッチのうち大きい方だけで計算。器具1台のときは判定しない。
- 壁際の判定（壁距離 ≦ ピッチ÷2）は未実装（任意項目。壁距離の入力欄がないため）。

(5) 判定に作業面高さを使う
- 入力欄 `i-wp`（既定 0.85 m、0以上）。判定高さ H ＝ 取付高さ − 作業面高さ。
- H ≦ 0 のときは判定を止め、「取付高さが作業面以下です」と表示。計算自体は続ける（黙って補正しない）。
- 判定のしきい値（0.8〜1.5）は本ツールの目安値で、根拠として画面にも明記。

(6) 室指数 K（参考表示）
- K ＝ W×L ÷ (H×(W＋L))。H は(5)と同じ。取付高さが空欄、または H ≦ 0 のときは非表示。
- U は自動設定しない。注意書きを常時表示。

(7) 保守率プリセットに「新品時・短期使用 1.00」を追加（1.00 以下の制限は従来どおり）。

(8) 用途別の推奨照度ボタン（必要照度欄に値を入れるだけ）
- 750 / 500 / 300 / 200 / 150 / 100 lx。
- 画面に出典と法令の最低値（事務所衛生基準規則：一般的な事務作業 300 lx 以上）を表示。
- **未検証**：JIS Z 9110 の最新版（2024年版）の実物との照合は未実施。コード内にも `未検証` と明記。

(9) 版数表示・印刷フッター・コードのヘッダを v0.2.0 に更新。

## 2. データ構造（保存・読込）
- v0.1.0 には JSON 保存・読込がないため、今回は追加していない。
- 将来 JSON 保存を追加する場合の既定キー（引き継ぎ用）：
  - `workPlaneH`：作業面高さ（既定 0.85、旧JSON読込時は 0.85）
  - `adoptN`：採用台数（既定 空欄＝計算台数を使用、旧JSON読込時は空欄）
- キーは足すだけ。消す・名前を変える操作はしない。

## 3. 計算ロジック
- 光束法の式は v0.1.0 から変更なし。
  - A ＝ W×L、F_req ＝ A×E、F_eff ＝ F×M×U、N ＝ 切り上げ(F_req÷F_eff)
  - 実効照度 ＝ N'×F_eff÷A（N' ＝ 採用台数。未入力なら N）
- 判定高さ H ＝ 取付高さ − 作業面高さ。間隔÷H の目安しきい値 0.8〜1.5（本ツールの目安値）。
- 室指数 K ＝ W×L÷(H×(W＋L))（参考のみ）。

## 4. 既知の制限・未確定事項
- 推奨照度（JIS Z 9110）の値は最新版との照合が未実施。
- 壁際判定（壁距離 ≦ ピッチ÷2）は未実装（任意項目）。
- 印刷は A4 縦2ページになる（簡易配置案は2ページ目）。見出しと本体は分かれない。1ページ化は未対応。
- 複数エリア合算（C-1）、利用率の自動算出（C-2）は見送り（Pro 側で扱う方針）。
- 室指数 K から U を決める機能は持たない（器具メーカーの照明率表で確認）。
